# Management operations

- **Configuration:** keep project-specific choices in `.planning/config.json`; do not copy credentials or model secrets into the repository.
- **Workstreams:** give each stream an owner, outcome, dependency set, state, and integration check.
- **Handoff:** record a compact, decision-ready continuation and refresh the native context snapshot.
- **Ship:** require fresh tests, reviewed changes, destination confirmation, and the user's publishing authority.
- **Inbox:** capture unplanned work with provenance and priority; do not silently insert it into the active phase.
