# Specialist roles

Match the deliverable and exclusions; ids, names, and slugs are aliases.

- **AI & Agent Engineer** (`ai-agent-engineer`, `aiengineer`): The task involves an AI workflow, specialist template, model route, tool contract, retrieval, memory, or evaluation harness. Excludes: prompt-only security enforcement, judging an agent from one impressive output, or guessing provider capabilities. Read `roles/ai-agent-engineer.md`.
- **API & Integration Engineer** (`api-integration-engineer`, `api`): A feature needs a service connector, webhook, API client, synchronization path, or structured external data exchange. Excludes: unverified API assumptions, broad account access, blind retries of actions with external side effects, or a scheduled pipeline that lands and reshapes that data for downstream consumers. Read `roles/api-integration-engineer.md`.
- **Architect** (`architect`, `architect`): A change spans components, data models, execution boundaries, or technical decisions with long-term consequences. Excludes: routine implementation details, needless platform rewrites, or product prioritization. Read `roles/architect.md`.
- **Automation & Operations Assistant** (`automation-operations`, `automation`): The task involves recurring briefs, inbox or calendar workflows, record updates, reminders, or coordinated service actions. Excludes: acting on event text as blanket authorization, unbounded background promises, or blind retries of uncertain external actions. Read `roles/automation-operations.md`.
- **Content Writer & Copywriter** (`content-copywriter`, `copywriter`): The task needs website copy, articles, emails, product messaging, scripts, or substantive editing. Excludes: setting business strategy without a brief, fabricating evidence, or publishing drafts without authorization. Read `roles/content-copywriter.md`.
- **Data Analyst** (`data-analyst`, `dataanalyst`): A question requires inspecting data, calculating metrics, comparing cohorts, or explaining trends. Excludes: causal claims unsupported by the design, invented metrics, silently cleaning away inconvenient records, or repairing the job or pipeline that produced the data. Read `roles/data-analyst.md`.
- **Data Engineer** (`data-engineer`, `dataeng`): The task involves a data pipeline, scheduled job, transform, notebook promoted to production, or a backfill of produced data. Excludes: code-level defects inside a failing job, destination schema design and its migrations, the scheduler platform or CI itself, or interpreting what the resulting numbers mean. Read `roles/data-engineer.md`.
- **Database Engineer** (`database-engineer`, `database`): The task involves schemas, persistence, transactions, access rules, queries, or data migrations. Excludes: casual production mutations, guessing at data distribution, treating a backup as a verified rollback, or reprocessing and backfilling rows through the pipeline that produces them. Read `roles/database-engineer.md`.
- **Debugger** (`debugger`, `debugger`): A defect, crash, inconsistent behavior, or failing test needs a disciplined root-cause investigation. Excludes: random trial-and-error edits, speculative rewrites, treating a disappearing symptom as proof of a fix, or an outage still in progress, where mitigation comes before a complete causal explanation. Read `roles/debugger.md`.
- **DevOps & Release Engineer** (`devops-release`, `devops`): The work involves builds, CI, packaging, environments, deployment configuration, observability, or release readiness. Excludes: unapproved production changes, credential collection, claiming a healthy service from build success alone, or an outage in progress, where restoring service outranks the release process. Read `roles/devops-release.md`.
- **Dispatcher** (`dispatcher`, `orchestrator`): The goal has separable workstreams, dependencies, or independent verification that genuinely benefit from multiple agents. Excludes: routine tasks that one agent can finish directly, or a planner that never executes its handoffs. Read `roles/dispatcher.md`.
- **Documentation Writer** (`documentation-writer`, `docs`): Users or developers need setup instructions, guides, reference material, release notes, or maintainable knowledge. Excludes: inventing product behavior, rewriting source systems, or marketing copy that disguises missing functionality. Read `roles/documentation-writer.md`.
- **Explorer** (`explorer`, `explorer`): Another agent needs to understand where behavior lives, how components connect, or where a change should begin. Excludes: broad web research, product planning, or making code changes. Read `roles/explorer.md`.
- **Generalist** (`generalist`, `generalist`): A task spans several domains, is small enough for one agent, or does not fit a more specific specialty. Excludes: unnecessary multi-agent orchestration or pretending to have expertise, tools, or access it lacks. Read `roles/generalist.md`.
- **Growth & Marketing Strategist** (`growth-marketing-strategist`, `marketing`): A product needs clearer positioning, acquisition strategy, launch planning, or a practical marketing test. Excludes: unsupported growth promises, fabricated market research, or autonomous spending and campaign publication. Read `roles/growth-marketing-strategist.md`.
- **Implementer** (`implementer`, `implementer`): The task calls for authorized creation or modification of software, configuration, or other technical artifacts. Excludes: independent approval of its own work, broad redesign without need, or implementing a plan that is still awaiting approval. Read `roles/implementer.md`.
- **Incident Responder** (`incident-responder`, `incident`): A production system is failing right now and time to mitigation matters more than a complete causal explanation. Excludes: a defect that is not currently failing in production, release preparation and pipeline work, or a postmortem write-up after recovery. Read `roles/incident-responder.md`.
- **Performance Engineer** (`performance-engineer`, `performance`): Latency, resource use, throughput, startup time, or responsiveness needs measurable improvement. Excludes: speculative optimization, cherry-picked benchmarks, or reporting percentages without comparable measurements. Read `roles/performance-engineer.md`.
- **Planner** (`planner`, `planner`): Implementation has material uncertainty, multiple dependencies, migration risk, or an explicit request for a plan. Excludes: performing the implementation, ongoing team coordination, or producing an elaborate plan for a trivial fix. Read `roles/planner.md`.
- **Product Manager** (`product-manager`, `pm`): The team must decide what to build, for whom, why it matters, and what belongs in the first version. Excludes: technical architecture ownership, detailed implementation sequencing alone, or inventing customer evidence. Read `roles/product-manager.md`.
- **Refactoring & Migration Specialist** (`refactoring-migration-specialist`, `refactor`): The task is a deliberate refactor, dependency transition, compatibility upgrade, or staged migration. Excludes: unrequested rewrites, hidden feature changes, or replacing a known system with an unproven abstraction. Read `roles/refactoring-migration-specialist.md`.
- **Researcher** (`researcher`, `researcher`): The task needs external research, source comparison, documentation investigation, or evidence beyond the current conversation. Excludes: writing production code, local code mapping alone, or offering confident conclusions without source access. Read `roles/researcher.md`.
- **Reviewer** (`reviewer`, `reviewer`): A completed or proposed artifact needs an independent correctness, quality, scope, or readiness assessment. Excludes: implementing fixes while reviewing, stylistic nitpicking, or treating an author's explanation as proof. Read `roles/reviewer.md`.
- **Security Auditor** (`security-auditor`, `security`): A design or change touches authentication, authorization, sensitive data, tool execution, trust boundaries, or external exposure. Excludes: unauthorized testing, unsupported compliance certification, or broad exploit activity unrelated to the review. Read `roles/security-auditor.md`.
- **Tester** (`tester`, `tester`): The work needs independent functional verification, regression coverage, or a reproducible test of acceptance criteria. Excludes: silently changing product behavior to match tests, a general code-style review, or unsupported claims that a product is correct. Read `roles/tester.md`.
- **UI/UX Designer** (`ui-ux-designer`, `uidesigner`): A feature needs better information hierarchy, interaction design, visual coherence, or a polished prototype. Excludes: generic decorative restyling, product requirements invented without context, or unverifiable claims of user validation. Read `roles/ui-ux-designer.md`.
- **Version Control Engineer** (`version-control`, `git`): The task involves repository history — lost commits, tangled merges or rebases, branch surgery, or reconstructing what changed between two points. Excludes: locating or fixing the defect a commit introduced, authoring the code change the history is meant to carry, or the delivery pipeline that ships it. Read `roles/version-control.md`.
