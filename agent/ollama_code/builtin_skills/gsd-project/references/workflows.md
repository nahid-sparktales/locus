# Project operations

## Initialize

Create `.planning/PROJECT.md`, `ROADMAP.md`, and `STATE.md` only after inspecting the workspace. `PROJECT.md` holds durable intent and constraints; `ROADMAP.md` holds milestone/phase outcomes; `STATE.md` holds the resumable present.

## Milestone

Give each milestone a user-visible outcome and verification boundary. Decompose it into phases small enough to plan accurately but large enough to deliver coherent value.

## Audit

Compare goals, roadmap, state, repository, tests, and recent changes. Flag missing coverage, stale claims, orphaned work, and dependency inversions.

## Complete

Run the milestone's verification, record shipped outcomes and deviations, move unresolved items forward explicitly, and set the next milestone or project-complete state.
