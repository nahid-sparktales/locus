# Quality operations

- **Code review:** inspect the diff in context, test changed behavior, report only actionable defects, and distinguish pre-existing issues.
- **Debug:** reproduce, trace from symptom to cause, test the hypothesis, apply the smallest root-cause fix, and guard against regression.
- **Security:** map trust boundaries and sensitive data, inspect authentication/authorization/input handling, and avoid printing secrets.
- **Evaluation:** define a representative prompt/task set, measurable criteria, baselines, and regression thresholds before comparing behavior.
- **UI:** verify loading, empty, error, populated, long-content, keyboard, accessibility, and constrained-window states.
