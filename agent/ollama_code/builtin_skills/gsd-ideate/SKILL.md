# GSD Ideate for Locus

Adapted from Get Shit Done by Lex Christopherson under the MIT License.

1. State the question the exploration must answer and the decision it unlocks.
2. Inspect existing constraints before proposing ideas.
3. Use Grill Me for unresolved user preferences; use a bounded spike only when conversation or static inspection cannot settle the question.
4. Keep prototypes explicitly disposable and separate evidence from production commitments.
5. Convert the chosen direction into a concise specification or roadmap input; capture rejected alternatives and why they lost.

Read `references/workflows.md` for explore, sketch, spike, specification, and capture operations.

Pre-flight: confirm the exploration answered its original decision, remove throwaway artifacts unless the user wants them, and do not present a prototype as production-ready.
