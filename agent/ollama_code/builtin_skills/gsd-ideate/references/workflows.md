# Ideation operations

- **Explore:** enumerate viable directions, constraints, unknowns, and discriminating questions.
- **Sketch:** produce the smallest representation that makes a flow, state model, or interface decision visible.
- **Spike:** time-box a runnable experiment around one uncertainty; define success and disposal before writing code.
- **Specify:** capture outcome, users, constraints, flows, interfaces, edge cases, and acceptance criteria at implementation-ready depth.
- **Capture:** add worthwhile but inactive ideas to the backlog with context; do not derail the active phase.
