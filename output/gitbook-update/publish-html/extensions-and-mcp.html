Locus combines installable extensions with bundled development workflows.

  • Manage Extensions & MCP covers servers, authentication, resources, prompts, tasks, and per-profile access.
  • Workspace Knowledge & Memory covers the local index, approved memory, encryption, and recall.
  • Bundled Workflows, Notebook & Continuity covers Task Observer, Superpowers, Grill workflows, Notebook, Notes, and encrypted handoffs.

Extensions do not increase the selected permission mode. A capability appears to an agent only when enabled at the workspace/profile boundary and permitted for that route. Stored configuration stays intact when a capability is disabled.

Document knowledge and private profiles

Library adds opt-in document knowledge and saved output versions. Identity Vault keeps private profile details and documents in a separate encrypted workflow with explicit review before release.
