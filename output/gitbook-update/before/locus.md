# Locus

A native macOS workspace for building with local or hosted AI models.

Locus 2.1 is a native macOS workspace for chatting, planning, building, browsing, reviewing, and supervising AI work. It brings project context, Git changes, a retained terminal, an agent-drivable browser, scheduled tasks, mobile access, local notes, and bounded agent teams into one SwiftUI app.

{% hint style="success" %}
**Local by default.** A fresh installation uses your own Ollama runtime. Locus sends data to a hosted provider only after you add and select an account or explicitly allow hosted team routing.
{% endhint %}

## What 2.1 brings together

* **Just Chat, adaptive Work, Plan, and Grill** with visible permission boundaries. Grill asks one question at a time and does not modify the project.
* **A real browser** with trusted input, coordinate targeting, responsive tabs, mobile emulation, screenshots, named dev servers, and a Keychain-backed Autofill vault.
* **Project context and continuity** through attachments, file mentions, context packs, local search, a searchable Notebook, approved memory, and encrypted handoffs.
* **Git and Terminal** with per-hunk review, branches, fetch/pull/push, checkpoints, retained processes, and reliable produced-file detection.
* **Local and hosted models** including Ollama, ChatGPT-plan access, OpenAI API, Claude, Kimi, and compatible endpoints.
* **Durable Solo and team work** with bounded delegation, editable plans, run-scoped evidence, recovery, evaluation, and usage visibility.
* **Schedules and Locus Mobile** for supervised work away from the main window.
* **Skills, MCP, model routing, and proxy profiles** with deny-by-default policies and no silent paid fallback.
* **Locus Vault private alpha** for a guarded Sepolia wallet experience in signed direct-download builds.

{% hint style="info" %}
These docs describe **Locus 2.1.0** for Apple Silicon Macs running macOS 14 or newer.
{% endhint %}
