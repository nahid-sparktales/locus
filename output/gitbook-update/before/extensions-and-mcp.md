# Extensions & MCP

Add plugins, skills, MCP tools, Notebook workflows, and private continuity without expanding permissions.

Locus combines installable extensions with bundled development workflows.

* [Manage Extensions & MCP](/locus-docs/extensions-and-mcp/manage-extensions-and-mcp.md) covers servers, authentication, resources, prompts, tasks, and per-profile access.
* [Workspace Knowledge & Memory](/locus-docs/extensions-and-mcp/workspace-knowledge-and-memory.md) covers the local index, approved memory, encryption, and recall.
* [Bundled Workflows, Notebook & Continuity](/locus-docs/extensions-and-mcp/bundled-workflows-notes-and-continuity.md) covers Task Observer, Superpowers, Grill workflows, Notebook, Notes, and encrypted handoffs.

Extensions do not increase the selected permission mode. A capability appears to an agent only when enabled at the workspace/profile boundary and permitted for that route. Stored configuration stays intact when a capability is disabled.
