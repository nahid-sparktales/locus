# Notebook

Open **Notebook…** from the sidebar menu or press **⇧⌘9**. It brings your standalone notes together with the existing workspace, chat, and shared notes.

Choose **New Note** to create a blank note immediately, then type its title and start writing. While Notebook is frontmost, **⌘N** creates another note. Notes save automatically; a failed save stays visible with a **Retry** action.

The note menu and each row's context menu offer **Rename**, **Duplicate**, **Pin**, and **Move to Recently Deleted**. A duplicate is an independent standalone note and keeps the original formatting. Renaming a workspace or chat note changes its notebook title without changing which workspace or chat owns it.

Pinned notes appear first. Use sorting to find recently edited notes or browse by title. Search includes the complete note text, not only the short preview. The editor also supports formatting, checklists, Find, Copy All, and export as text or RTF.

## Recently Deleted

Deleted notes remain in **Recently Deleted** until you explicitly remove them. You can preview and restore them, or confirm **Delete Permanently** or **Empty Recently Deleted**. There is no automatic deletion deadline.

Deleting a workspace, chat, or shared note also pauses editing in its Notes panel. Restore the note there or in Notebook. After permanent deletion, the panel lets you explicitly start a new blank note. Already queued saves cannot bring back the old content.

## Local storage

Standalone notes stay local to the current Locus edition. They are not automatically available through the agent's contextual Notes tools. Existing workspace, chat, and shared notes keep their current behavior and file locations. This feature does not add sync, folders, tags, or AI processing.
